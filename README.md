# BebinC

Professional landing page for [Charles Bébin](https://www.linkedin.com/in/charles-bebin/) — [bebinc.com](https://bebinc.com).

## Tech Stack

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS 4**
- **Framer Motion**

## Features

- Hero section with animated entrance
- About section with bio and highlights
- Content gate (paywall-style blur) funneling visitors to LinkedIn
- Experience timeline with skill tags
- Education cards (ESSEC BBA, Baccalauréat)
- Contact section with email and LinkedIn links
- Responsive navigation with mobile menu
- Dark finance-inspired aesthetic (navy, gold, cream)

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy

Deploy to [Vercel](https://vercel.com) for one-click deployment. Connect this repo and Vercel will auto-detect Next.js.
